# SCARCO V2 • Python Railway
Files: bot.py, requirements.txt, runtime.txt, database.json.

Railway:
- Build Command: leave empty
- Start Command: python bot.py
- Variables: DISCORD_TOKEN, CLIENT_ID, GUILD_ID

Main commands:
- /setup = configure most server settings in one command
- /giveaway = complete giveaway in one command (prize, duration, winners, channel, image, custom join emoji/label)
- /ticket-panel = publish ticket panel
- /ticket-add-type = add/edit ticket button + custom Nitro/server emoji
- /ticket-remove-type
- /verify-panel
- /vouch-panel
- /help

Custom Discord/Nitro emoji can be pasted as <:name:id> or <a:name:id> when Discord allows it.

Keep your token private.
